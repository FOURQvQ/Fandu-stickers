# 梵度长屋 · Fandu Stickers

把"造景贴纸书"搬进 3D：把贴纸从左边的贴纸页拖进一座剖开的三间长屋，贴纸落地的瞬间变成 3D 物件。全部贴完后切到俯视图，就是一张带 5 尺网格的跑团地图，可以导出 PNG。主题是 D&D 模组《Lost Mine of Phandelver》（梵度矿坑）里的冒险者长屋。

群核科技 Aholo 全球 3D AI 黑客松参赛作品。全部 110 个模型（89 件贴纸 + 21 件房屋构件）由 Aholo Lux3D 图生 3D 生成。

## 在线试玩

**https://fourqvq.github.io/Fandu-stickers/**

需要电脑浏览器和鼠标（建议 Chrome / Edge）。第一次打开要下载约 45 MB 的模型和贴纸，请稍等。

## 怎么玩

- 左边贴纸页按"仓储间 / 大厅 / 卧室"分类，按住一张贴纸拖进长屋。
- 靠近它该放的位置时，会出现橙色虚影并被吸过去，松手就贴上。
- 家具上的东西（桌上的碗、床上的被子）要先贴好下面那件家具。把家具拿起来，上面的东西会一起回到贴纸页。
- 右上角是成品图，点一下放大，对照着想东西该放哪。
- 左键拖空白处转视角，右键拖动平移，滚轮缩放。
- 全部贴完后点"俯视地图"，再点"导出地图 PNG"。
- 进度自动保存在浏览器里，刷新不会丢；"清空重来"会清掉存档。
- 右上角"手感调节"可以改吸附半径、落下速度、音效等。

## 本地运行

```
cd Fandu-stickers
python -m http.server 8000
```

然后用浏览器打开 http://localhost:8000 。不能直接双击 `index.html`，浏览器不允许网页读取本地文件。

## 文件

- `index.html`、`css/`、`js/`：游戏本体（纯 JavaScript + three.js 0.160，无构建步骤）
- `layout.json`：布局数据，由 `tools/build_layout.py` 生成
- `cards/`：贴纸卡片 PNG
- `models/`：压缩后的模型（`tools/prep.mjs` 减面、缩贴图），清单在 `models/index.json`
- `开发说明.md`：设计决策和实现细节；`待修问题.md`：已知问题
